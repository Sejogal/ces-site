Termos de Uso — Projeto CES (Cancioneiro do Exército de Salvação)

Última atualização: 21 de setembro de 2026

1. Aceitação dos Termos

Ao utilizar o Projeto CES, você concorda com estes Termos de Uso. Se não concordar, por favor deixe de usar o aplicativo.

2. Descrição do Projeto

O Projeto CES é um cancioneiro digital que disponibiliza letras de hinos do Exército de Salvação. O aplicativo é essencialmente de visualização de conteúdo — não possui comentários nem partilha entre utilizadores.

3. Registo e Dados Recolhidos

Ao abrir a app pela primeira vez, é pedido um registo único com nome, e-mail e corpo/paróquia, usado apenas para fins estatísticos internos. Não se trata de um sistema de login — não há palavra-passe nem autenticação necessária para usar a app depois do registo inicial. Para mais detalhes sobre como tratamos estes dados, consulta a Política de Privacidade.

4. Uso Permitido

  • Pode ler e navegar pelas letras para uso pessoal, culto, estudo ou ensaio.
  • É proibido reproduzir ou distribuir o conteúdo para fins comerciais sem autorização dos detentores dos direitos.
  • É proibido modificar o aplicativo ou fazer engenharia reversa sem permissão.

5. Propriedade Intelectual

As letras e materiais exibidos pertencem aos respetivos titulares (Exército de Salvação ou autores). O layout, design e código do aplicativo são propriedade dos desenvolvedores do Projeto CES.

6. Erros de Digitação e Correções

Apesar do cuidado na transcrição das letras, pode haver erros de digitação ou versões diferentes das publicadas em partituras físicas. Se encontrares um erro, podes reportá-lo diretamente a partir do próprio aplicativo (funcionalidade Reportar erro). As sugestões serão avaliadas e, quando apropriado, atualizaremos a letra.

7. API de Letras (Futuro)

Em breve disponibilizaremos uma API oficial para acesso às letras. Quando a API estiver ativa divulgaremos documentação e condições de uso. Até lá, o aplicativo continua a funcionar apenas como cliente de visualização.

O Projeto CES esforça-se por fornecer letras corretas, mas não garante total precisão. O aplicativo não se responsabiliza por erros nas letras, interrupções do serviço ou uso indevido do conteúdo.

Podemos atualizar o conteúdo ou a interface do app a qualquer momento. O uso continuado após alterações implica aceitação dos novos termos.
